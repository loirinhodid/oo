# Rover Client — Independent Launcher

Launcher pessoal e independente para organizar e iniciar jogos já instalados localmente.

## Princípios

- Cada jogo possui sua própria página e identidade visual.
- O usuário escolhe o executável `.exe` local.
- O launcher apenas inicia o executável; não instala, atualiza ou modifica os jogos.
- Capas, fundos e mídias são personalizáveis por jogo.
- Interface preparada para Electron/Windows.
- Arquitetura preparada para backend próprio no futuro.

## Funcionalidades planejadas

- Biblioteca e busca de jogos
- Filtros por gênero
- Página individual por jogo
- Capa e background personalizados
- Imagens, GIFs e vídeos por arquivo ou URL
- Descrição, gênero e informações do jogo
- Caminho do executável e abertura da pasta
- Perfil, amigos, XP, níveis e missões
- Barra social e serviços pessoais
- Controles de janela Electron

## Escopo

Este projeto não substitui Steam, Epic Games, launchers oficiais ou sistemas DRM. Ele funciona como uma camada pessoal de organização e inicialização dos jogos instalados no computador.
